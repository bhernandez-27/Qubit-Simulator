# Qubit Simulator
Welcome To Qubit Simulator!
This is an educative resource intende to help users better understand how qubits are represented and manipulated on the Bloch Sphere through manually plotting and manipulating qubits themselves!

The app can be accessed through Vite using `npm run dev` or on the website hosted on Github Pages: https://bhernandez-27.github.io/Qubit-Simulator/

A log of the journey in building this app can be found in [journey.pdf](./journey.pdf).

Credits: 
The logic for this app was based off of the knowledge I gained in Introduction to Quantum Computing (PHYS 33500) at CCNY with Professor Seth Cottrell and subsequentially his book 
"Quantum Computation: An Introduction for Undergraduates" (https://www.dropbox.com/scl/fi/xhtoatg130cgs4upo5lrk/Cottrell.pdf?), I would highly recommend reading it and if possible taking a class with him, as the inspiration and knowledge for this app came mostly from doing exactly so myself.
